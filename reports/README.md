# Fix Pack Dashboards

This folder is for Phase 2 manual private dashboards.

## Manual delivery flow

1. Customer buys Fix Pack on Gumroad.
2. Customer submits CV, role, score, and notes through Tally:
   `https://tally.so/r/44p06b`
3. Copy `fixpack-dashboard-template.html`.
4. Rename it with a private-looking slug, for example:
   `reports/fp-2026-05-jane-k7x2.html`
5. Edit the copied file with the customer's real dashboard content.
6. Commit and push.
7. Send the customer the GitHub Pages dashboard link by email.

## Link format

After GitHub Pages is active, the link will look like:

`https://yabato-co.github.io/fixsend/reports/fp-2026-05-jane-k7x2.html`

Use non-obvious filenames. This is a lightweight MVP private link, not secure authentication.
